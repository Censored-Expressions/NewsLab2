# Editorial Quality Execution Threshold Teaching

Date: 2026-06-28
Target: Creator Desk, Editorial Synthesis, News Creation

## Problem
The Framework preserved owner feedback about mixed stories, copied wording, repetitive language, and topic mismatch, but repeated feedback showed that lesson application was still not strong enough.

## New Rule
Creator Desk drafts must pass both issue-specific review and a minimum self-review score. If a draft scores below 82, the Brain must rebuild the editorial from cleaned story facts before publishing.

## Required Behavior
- Do not publish copied source previews.
- Do not combine unrelated supporting stories.
- Do not attach opinion frames from one story to a different story.
- Do not use repeated stock phrases as a substitute for story-specific judgment.
- If quality is weak, rebuild the current/past article and log the rewrite as execution, not just memory capture.

## Success Standard
The Brain closes the loop when owner feedback produces a changed public editorial, a self-review score, and proof that copied/mixed/generic patterns were removed.
